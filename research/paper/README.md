# SemanticSync Evidence Package

This package gathers the current venue-neutral research narrative and evidence while preserving the source records and avoiding manually duplicated technical claims.

| Artifact | Purpose / source of truth |
|---|---|
| `CORE_RESEARCH_NARRATIVE.md` | Bounded problem statement and contribution proportional to current evidence. |
| `CONTRIBUTIONS_AND_RQS.md` | Research questions, evidence, and current answer status. |
| `EXPERIMENTAL_RESULTS.md` | Machine-validated historical SET matrix and the separate explicit-INCREMENT pilot. |
| `THREATS_TO_VALIDITY.md` | Construct, internal, external, and conclusion validity limitations. |
| `RELATED_WORK_MATRIX.md` | Redirect to the maintained source-grounded matrix at `research/related_work/RELATED_WORK_MATRIX.md`; do not copy it. |
| `REFERENCE_AUDIT.md` | Redirect to `research/related_work/REFERENCE_VERIFICATION.md` and local-PDF inventory. |
| `CLAIM_EVIDENCE_REGISTER.md` | Redirect to `research/audit/CLAIM_EVIDENCE_REGISTER.md`; this is the maintained register. |

These materials do not establish a novel algorithm, universal correctness, a general performance advantage, or submission readiness. The manuscript remains the human-readable paper source; benchmark claims must be regenerated or checked from raw artifacts using the commands in `research/experiments/runs/README.md`.
